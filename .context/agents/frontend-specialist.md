## Mission

Own the user-facing surface: Remix routes, React components, the design system, and the wizards. Build accessible, fast, internationalised flows that respect the layered architecture (UI → tRPC → services).

## When to Use

- Adding or modifying a route under `apps/remix/app/routes/`.
- Building or extending a component in `packages/ui/` or `apps/remix/app/components/`.
- Implementing a wizard step in `packages/ui/primitives/document-flow` or `template-flow`.
- Designing a new dialog, table, or form in the dashboard.
- Touching the embed iframe flows (`/embed/v1/*`, `/embed/v2/*`).
- Adding a Radix primitive or a Tailwind variant to the design system.

## Workflow

1. **Read the spec / design** — confirm acceptance criteria and the test plan.
2. **Map to the design system** — find the closest primitive in `packages/ui/`; if none fits, design a new one with the same conventions.
3. **Plan the route structure** — pick the right route group (`_authenticated`, `_recipient`, `_share`, `_unauthenticated`, `embed`, `api`, `_internal`).
4. **Wire data**:
   - Loaders use the tRPC server-side caller (or the `loader` helper).
   - Mutations go through tRPC procedures, not direct fetch.
   - Forms use `react-hook-form` + Zod with the schemas from `packages/prisma/generated/zod`.
5. **Render**:
   - Tailwind tokens from `packages/tailwind-config`.
   - Radix primitives for keyboard / focus management.
   - Recipient color tokens from `packages/ui/lib/recipient-colors.ts`.
6. **i18n** — every string is a translation key; entries in every locale under `packages/lib/translations/`.
7. **A11y** — labels, focus traps, keyboard shortcuts, color contrast.
8. **Test**:
   - Storybook-style snapshot where useful.
   - Playwright in `packages/app-tests/e2e/<flow>/` for end-to-end.
   - Axe checks for key signing pages.
9. **Document** — public docs in `apps/docs`; visual changes ship a screenshot or recording.

## Project Conventions

- **Route groups** — `_authenticated` (signed-in user), `_recipient` (token URL), `_share` (token URL, public), `_unauthenticated` (login/signup), `embed` (iframe), `api` (Hono), `_internal` (Hono internals).
- **Layouts** — `apps/remix/app/routes/_authenticated+/t.$teamUrl+/...` for team-scoped routes; the layout enforces team membership.
- **Wizards** — `packages/ui/primitives/document-flow` and `template-flow`; each step is a `*FormPartial` driven by `DocumentFlowStep`.
- **Tables** — `apps/remix/app/components/tables/`; use `virtual-list` for long lists.
- **Forms** — `react-hook-form` + Zod; `useForm` is the canonical hook.
- **Dialogs** — Radix Dialog + the `apps/remix/app/components/dialogs/` patterns.
- **Toasts** — `packages/ui/primitives/use-toast`; never roll a custom toast.
- **PDF preview** — `react-pdf` and `apps/remix/app/components/general/pdf-viewer`.
- **Signature pad** — `packages/ui/primitives/signature-pad`.
- **Recipient colors** — generated by `getRecipientColor`; never hardcode.
- **Date format** — `DD/MM/YYYY HH:mm` in `pt-BR`; use `formatDate`.
- **i18n** — `useTranslation` / `Trans`; never inline strings.
- **Strict TypeScript** — no `any`; tRPC types flow from the router to the client.

## Output Format

- **Routes / files touched**: paths and line ranges.
- **Design system impact**: new primitives added to `packages/ui/`.
- **i18n keys**: new keys with locale coverage.
- **A11y notes**: keyboard interactions, ARIA, focus management.
- **Tests**: Playwright + axe paths.
- **Screenshots / recordings**: required for UI changes.
- **Sensors**: which `.context/harness/sensors.json` sensors gate the change (e.g. `i18n-keys-present`, `axe-a11y`).
